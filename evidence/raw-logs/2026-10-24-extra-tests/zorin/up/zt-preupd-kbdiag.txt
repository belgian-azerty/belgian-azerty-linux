== be_capslock symbols
// Caps Lock as on Windows "Belgian (Period)" / "Belgian (Comma)" (KBDBE / KBDBENE): every key of the main block
// that has CAPLOK on Windows gives its Shift level with Caps Lock, and Shift+Caps Lock gives the base level again.
// Letters already behave like this; this changes the digits row and the punctuation keys. ² and < stay as they are,
// as on Windows. AltGr symbols are not affected by Caps Lock (Lock+LevelThree = Level3).
// Same mechanism as xkeyboard-config's capslock(digits_row) (2.42+), extended to the punctuation keys.
